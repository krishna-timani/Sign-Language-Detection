\# Sign Language Detection



An AI-powered project exploring sign language gesture recognition using Python and deep learning.



\## Overview



This project uses a trained machine learning model to recognize sign language gestures. It includes scripts for data collection, model training, evaluation, and real-time detection.



\## Features



\- Sign language data collection

\- Deep learning model training

\- Model evaluation

\- Real-time gesture detection

\- Gesture class label mapping



\## Tech Stack



\- Python

\- TensorFlow / Keras

\- Machine Learning

\- Computer Vision



\## Project Structure



\- `datacollection.py` — Data collection

\- `train\_model.py` — Model training

\- `evaluate\_model.py` — Model evaluation

\- `realtimedetection.py` — Real-time detection

\- `class\_names.json` — Gesture class labels

\- `Data/` — Project data
